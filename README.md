# 🚀 MyPortfolio — A Creative, AI-Assisted Developer Portfolio

Welcome to **MyPortfolio**, a clean, single-page personal website crafted using [**Bolt**](https://www.bolt.fun/) and AI-powered tools. This portfolio serves as my digital space to showcase my journey, technical skills, and personal brand — all designed with performance, simplicity, and elegance in mind.

> 🧠 "First impressions matter — let your work speak before you do."

---

🔗 **Live Website**: [nitinmehra.netlify.app](https://nitinmehra.netlify.app/)  
📁 **Repository**: [github.com/nitinmehra09/MyPortfolio](https://github.com/nitinmehra09/MyPortfolio)

---

### 🛠️ Tech Stack & Tools

- **Bolt.fun** – For rapid, no-code/low-code visual development  
- **AI Tools** – Used for generating copy, design ideas, and content layouts  
- **HTML / CSS / JavaScript** – For fine-tuning and enhancements  
- **Netlify** – For seamless deployment and continuous hosting  

---

### ✨ Key Features

- 👤 About Me — Personal background and aspirations  
- 🧠 Skills — Technical capabilities and learning path  
- 📂 Projects — Highlights with GitHub links  
- 📜 Certifications — Verified credentials from my journey  
- 📱 Fully Responsive — Looks great on desktop and mobile  
- 📬 Contact Me — Quick links to connect
